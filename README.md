# Ktor Practice Project

This project is a simple Ktor server created as part of the practical work.

## Completed tasks:
- Created a new Ktor project.
- Ran it via Gradle and IntelliJ IDEA.
- Changed the default port (set to 9292).
- Added a new HTTP endpoint `/test1`.
- Uploaded the project to GitHub with initial commit.

## How to run:
1. Run the project with:  
   `./gradlew run`
2. Open in browser:  
   http://0.0.0.0:9292  
   http://0.0.0.0:9292/test1
